FLAPs – Online Deployment

Enthalten:
- app.py
- requirements.txt
- flaps_logo.png

Für Streamlit Community Cloud:
1. Dateien in ein GitHub-Repository laden.
2. In Streamlit Community Cloud das Repository auswählen.
3. Main file path: app.py
4. Deploy.

Die App erwartet flaps_logo.png im selben Ordner wie app.py.
